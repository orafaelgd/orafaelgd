# Rafael Gaudencio Dias

**Estagiário em Desenvolvimento de Software | Back-end | Java**

Sou estudante de **Engenharia de Software na PUC-Campinas** e técnico em **Desenvolvimento de Sistemas pela Etec Ferrucio Humberto Gazzetta**.

Atualmente, atuo como estagiário em desenvolvimento de software, trabalhando com PHP. Tenho interesse em desenvolvimento back-end, APIs e bancos de dados relacionais, com foco em aprofundar meus conhecimentos no ecossistema Java e na manutenção e evolução de sistemas legados.

Busco oportunidades de estágio ou de desenvolvedor back-end júnior, nas quais possa contribuir com o desenvolvimento de software e ampliar minha experiência profissional.
